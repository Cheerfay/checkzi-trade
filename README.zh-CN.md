# Checkzi

[English](README.md) | [简体中文](README.zh-CN.md)

**重要决策，Checkzi 一下。**

[体验 Checkzi Trade](https://checkzi.app/zh) · 支持 English 和中文

Checkzi 是一个面向重要决定的自查平台。当情绪、紧迫感或不完整的信息可能跑在判断前面时，它帮助用户先把决定写下来，看清是什么在推动自己，并在行动前完成一个有用的小步骤。

[Checkzi Trade](https://checkzi.app/zh) 是目前首个、也是唯一已经上线的场景。它是一款为有一定交易经验的股票交易者设计的交易决策自查工具，解决情绪上头时容易仓促下单、事后才发现理由站不住的问题。下单前写下理由、仓位和情绪，看清是什么在推动自己，再由自己决定是否行动。

## 为什么做 Checkzi

一些代价很高的决定，并不是因为缺少信息，而是发生在“知道自己的规则”和“在压力下采取行动”之间的短暂距离里。

Checkzi 为这段距离提供一个结构化的暂停：让当下的理由变得可见，但不假装软件应该接管最终选择。

## 当前上线场景：Checkzi Trade

1. 用自己的话描述准备执行的交易。
2. 获得一张简洁的自查卡，检查理由、情绪和计划完整度。
3. 如有需要，补充整体持仓，再检查集中度、调整节奏和现金余地。
4. 保存历史卡片，逐渐看见自己的交易习惯。

Checkzi Trade **不预测价格、不推荐证券，也不告诉用户应该买入、卖出或持有。**

## 平台方向

未来，Checkzi 可以延展到其他适合先做一次短暂、边界清楚的自查的决策场景。每个场景都应该保留同一组核心：

- 让用户用自己的话写下真实决定；
- 区分事实、假设、压力和缺失信息；
- 先应用场景专属规则，再由模型生成解释；
- 给出一个与风险相称的下一步，而不是权威答案；
- 保留用户的决定权，并清楚说明产品边界。

目前只有 Trade 已经上线。其他场景是产品方向，不是已经交付的能力。

## 关键产品判断

- **暂停，而不是预测。** 改善决策质量，但不声称掌握确定答案。
- **先给一个有用的小动作。** 第一层结果保持简洁，更深的分析放在后面。
- **先由规则判断，再由模型表达。** 场景约束由确定性规则处理，语言模型负责把结果转成克制、易读的话。
- **边界也是产品的一部分。** Prompt、服务端校验和界面文案共同保证同一条边界。
- **从一开始就支持双语。** 核心产品路径同时提供英文和中文。

## 技术概览

- TanStack Start、React 19、TypeScript、Vite、Tailwind CSS
- Better Auth 与 Drizzle ORM
- 生产环境使用 Supabase/PostgreSQL
- 可切换的大语言模型 Provider、结构化输出与输入防护
- 部署于 Vercel
