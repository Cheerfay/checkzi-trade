# Trade Self-Check / 交易冷静卡

[English](README.md) | [简体中文](README.zh-CN.md)

**在情绪化交易之前，先暂停一下。**

[体验线上产品](https://tradeselfcheck.com) · 支持 English 和中文

交易冷静卡帮助个人投资者在行动前先停一下。用户写下准备执行的交易、背后的
理由和此刻的情绪，产品会把这些信息整理成一张简洁的自查卡：什么可能正在推动
这次决定、还有哪些问题没有说清，以及继续之前可以先做的一个小动作。

它**不预测价格、不推荐证券，也不告诉用户应该买入、卖出或持有。**

## 它解决什么问题

许多投资失误并不是因为缺少信息，而是发生在“知道自己的规则”和“在压力下采取
行动”之间的短暂距离里：追涨、被后悔推动、仓位过度集中，或在交易过程中临时
改变计划。

我做交易冷静卡，是为了让这段距离在最需要被看见的时刻显现出来。

## 使用方式

1. 用自己的话描述准备执行的交易。
2. 获得一张克制的自查卡，检查理由、情绪和计划完整度。
3. 如有需要，补充整体持仓，再检查集中度、调整节奏和现金余地。
4. 保存历史卡片，逐渐看见自己的交易习惯。

## 关键产品判断

- **暂停，而不是预测。** 产品改善的是决策质量，不假装知道某只证券接下来会
  怎么走。
- **先给一个有用的小动作。** 首屏只保留一句冷静锚点和一个下一步，更深的分析
  放在第二层。
- **先由规则判断，再由模型表达。** 数值和仓位约束由确定性规则处理，语言模型
  负责把结果转成克制、易读的话。
- **边界也是产品的一部分。** Prompt、服务端校验和界面文案共同保证同一条边界：
  不荐股、不择时、不提供目标价，也不编造数字。
- **从一开始就支持双语。** 核心产品路径同时提供英文和中文。

- 生产环境使用 Supabase/PostgreSQL
- 可切换的大语言模型 Provider、结构化输出与输入防护
- 部署于 Vercel
